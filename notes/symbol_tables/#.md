ck CPU — Bitwise API Reference Tables

## Instruction type (bit 15)

| Bit 15 | Instruction type |
|---|---|
| 0 | A-instruction |
| 1 | C-instruction |

## A-instruction layout

| Bits | Field |
|---|---|
| 15 | always `0` |
| 14-0 | 15-bit value (binary of the constant/address) |

## C-instruction layout

| Bits | Field |
|---|---|
| 15 | always `1` |
| 14-13 | unused (convention: `11`) |
| 12 | `a` |
| 11-6 | `c1 c2 c3 c4 c5 c6` (comp) |
| 5-3 | `d1 d2 d3` (dest) |
| 2-0 | `j1 j2 j3` (jump) |

## Predefined symbols (for the symbol table, needed for label/variable resolution)

| Symbol | Value |
|---|---|
| `SP` | 0 |
| `LCL` | 1 |
| `ARG` | 2 |
| `THIS` | 3 |
| `THAT` | 4 |
| `R0`-`R15` | 0-15 |
| `SCREEN` | 16384 |
| `KBD` | 24576 |

**Variable allocation rule:** any symbol referenced with `@symbol` that isn't a predefined symbol or a label defined with `(symbol)` gets allocated the next available RAM address, starting at **16** and incrementing by 1 for each new variable encountered.
